# THƯ MỤC ẢNH ĐỊA ĐIỂM (assets/locations/)

Đây là nơi bạn lưu trữ hình ảnh thực tế của các địa điểm hẹn hò.

## 1. Cách đặt tên file và định dạng
- Bạn có thể dùng các định dạng: `.jpg`, `.jpeg`, `.png`, hoặc `.webp`.
- Nên đặt tên file theo mã `id` của địa điểm trong file `script.js` (viết thường, không dấu, dùng dấu gạch ngang):
  - Ví dụ: `cafe-01.jpg`, `restaurant-01.jpg`, `movie-01.jpg`, `park-01.jpg`, `ho-tay.webp`

## 2. Kích thước và tỉ lệ khuyến nghị
- **Tỉ lệ khuyến nghị**: `16:9` hoặc `4:3` (ngang).
- **Kích thước tối ưu**: Chiều rộng từ `800px` đến `1200px` (dung lượng mỗi ảnh khoảng 100KB – 300KB để trang web tải cực nhanh trên 4G/5G điện thoại).
- Ảnh thực tế sẽ được hiển thị sắc nét tự nhiên (không bị làm mờ, không bị pixel hóa) trong khung card modal thông tin.

## 3. Nếu chưa kịp chuẩn bị ảnh thì sao?
- Đừng lo lắng! Nếu bạn chưa có ảnh hoặc file ảnh chưa tồn tại, hệ thống sẽ **tự động hiển thị huy hiệu Pixel Art biểu trưng** kèm tên địa điểm một cách duyên dáng và đồng bộ với phong cách game.
